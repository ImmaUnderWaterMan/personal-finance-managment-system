# Модуль месячных бюджетов

`BudgetModule` устанавливает и изменяет месячный лимит по категории, получает расходы через `IExpenseQueryService` и рассчитывает остаток. При расходах не больше лимита состояние равно `WithinLimit`, при превышении — `Exceeded`; остаток при этом отрицателен.

Лимит положителен, имеет не более двух знаков после запятой и соответствует `numeric(18,2)`. Категория должна принадлежать пользователю и иметь тип `Expense`. Уникальная запись определяется пользователем, категорией, годом и месяцем. Повторная установка заменяет лимит.

Период включает первый день выбранного месяца и исключает первый день следующего. Декабрь 9999 года не поддерживается, поскольку конец периода нельзя представить в `DateOnly`. Ошибка получения расходов не подменяется нулем и не позволяет сохранить новый лимит. Отсутствие расходов возвращает успешный ноль.

`userId` должен поступать из проверенного серверного контекста. Архивирование счета не удаляет исторические расходы из бюджета. Превышение лимита не блокирует регистрацию операций.

Хранилище `InMemoryBudgetRepository` пока работает в памяти. PostgreSQL, HTTP API и подключение WPF будут добавлены отдельно. Внешние модули используют `IBudgetService` из `PersonalFinance.Contracts.Budgets`.

Проверка: `dotnet test personal-finance-managment-system.slnx` в существующем локальном решении. В Git файлы решения не включаются.
