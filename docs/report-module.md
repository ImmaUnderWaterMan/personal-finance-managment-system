# Модуль финансовых отчетов

`ReportModule` использует только публичные интерфейсы `IAccountService`, `ITransactionService` и `IBudgetService`. Модуль не меняет данные и не имеет собственного хранилища.

`GetSummaryAsync` возвращает доходы, расходы, их разницу, расходы по категориям и остатки по счетам. Период включает `From` и исключает `ToExclusive`. Остаток на начало включает начальный остаток счета и все операции до `From`; остаток на конец дополнительно учитывает операции выбранного периода. Архивные счета сохраняются в отчете. Начальный остаток не включается в доходы.

`GetMonthlyBudgetsAsync` возвращает установленные бюджеты за календарный месяц, включая расходы, остаток и состояние. Категории без бюджета пропускаются; другие ошибки и отмена передаются вызывающему коду. Неполученные расходы не подменяются нулем.

Сведения ограничиваются переданным `userId`, который будущий API должен брать из авторизованного контекста. Чужие счета, категории и операции в отчет не включаются.

Пока данные поступают из модулей с хранилищами в памяти. Чтение разных модулей не представляет собой общий снимок транзакции: при одновременных изменениях итоговые данные могут относиться к разным моментам. Согласованный снимок будет обеспечиваться при реализации PostgreSQL. Все суммы выражены в рублях; валютная конвертация не выполняется.

Проверка: `dotnet test personal-finance-managment-system.slnx` в локальном решении. Интерфейс WPF и HTTP API этим изменением не подключаются.
