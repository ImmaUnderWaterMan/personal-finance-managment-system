# Интерфейс Personal Finance

WPF-клиент на C# / .NET 10. Откройте решение в Visual Studio и назначьте `PersonalFinance.Wpf` запускаемым проектом.

```powershell
dotnet run --project src/PersonalFinance.Wpf
```

Доступны обзор финансов, счета, поиск операций, месячные бюджеты и отчёт по категориям. Кнопка «Добавить операцию» открывает форму дохода или расхода с проверкой суммы и даты. После сохранения обновляются баланс, бюджеты и отчёты.

Пока используются демонстрационные данные. Изменения сохраняются только в памяти и теряются после закрытия окна. API, авторизация и PostgreSQL подключаются на следующих шагах. Счета и лимиты в этой версии заданы для демонстрации; их редактирование ещё не реализовано.
